# H3Hint — MiniMax H3 提示词工程编辑器

用 **C++ / Qt 6** 编写的桌面软件，用于创建和管理 **MiniMax H3（海螺 / Hailuo）** 视频生成提示词工程，并一键生成符合 H3 官方六段结构（`subject_definitions` / `summary` / `retention_analysis` / `detailed_description` / `overall_soundscape` / `non_diegetic_music`）的提示词。

## 功能

- **工程管理**：工程以 JSON 配置（`.h3json`），资源文件（图片 / 音频）使用相对路径，便于工程整体拷贝迁移。
- **资源分类管理**（左侧树）：
  - **角色**：普通角色与 Q 版内心小人；每个角色提供**一张四视图参考图**（面部特写 / 全身正面 / 全身侧面 / 全身背面 同图）、**多个音色音频参考**，普通角色可关联其 Q 版小人。
  - **场景**图片资源、**道具**图片资源：图片路径 + 作用说明。
- **分镜与镜头**：分镜（Sequence）是**视频级容器**，一个分镜可含多个**镜头 (Shot)**，每个镜头含多个**段落 (SubShot)** 与台词；分镜在左侧树中可**上下移动**，顺序即为分镜编号（无需手动编号）；树中**始终显示序号前缀**，如「1. 招新片段」，未命名时显示「2. 分镜2」；镜头可上下移动、编辑、删除。
  - 台词格式严格遵循：`<Subject N>(S<n>)[备注]使用<Audio N>说：“中文内容”`，其中 `(S<n>)` 按整段提示词的句子顺序跨镜头连续编号（S1、S2、S3…）；未选音色时省略 `使用<Audio N>`；自动使用中文引号，避免生成英文字幕。
- **应用内配置（独立于工程文件）**：常用画风、背景环境声音 (`overall_soundscape`)、背景音乐 (`non_diegetic_music`，默认 `N/A`) 等可复用条目统一存放在应用配置文件 `appconfig.json`（位于系统应用配置目录，如 `C:/Users/<用户>/AppData/Roaming/H3Hint/`），每种可多条、可增删改。通过菜单 **应用设置** 维护。
- **工程级约束**：画风约束保留在工程文件内；**嘴型约束、出场角色均下放到各分镜（Sequence）**（每个分镜独立配置，不同分镜可不同）。
- **工程提示词生成界面（独立窗口）**：菜单“生成提示词”打开独立界面，可随时从应用配置中**选用**常用画风（多选）、背景环境声音、背景音乐，结合当前工程的角色 / 场景 / 道具 / 分镜资源一键生成整份提示词，并可复制或保存为 `.txt`。
- **分镜出场角色可单独配置**：每个分镜的编辑器中可**从项目已有角色里勾选出场角色**（增删、查看顺序），也可移除；删除某角色时会自动从各分镜移除其引用。
- **分镜级资源选择**：分镜编辑页可分别从项目资源中**添加 / 移除本分镜使用的出场角色、场景、道具**（顺序决定 `<Subject N>` 编号）；即使 caption 未引用，也会作为定义出现在 `subject_definitions` 中。
- **统一编号为 `<Subject N>`**：生成时**每个分镜独立生成一份 H3 提示词**，**人物 / 场景 / 道具在本分镜内统一编号为 `<Subject N>`**（顺序：人物 → 场景 → 道具，先按分镜页配置的资源顺序，再兜底 caption 中引用的资源），`<Picture N>` 也随之连续编号；**生成结果中不再出现 `<Scene N>` / `<Prop N>`**。caption / 台词里仍用 `<Subject N>` / `<Scene N>` / `<Prop N>` 引用项目资源（按项目 id），生成时自动转换为统一的 `<Subject N>`；引用到但未配置的资源会自动追加，避免悬空引用。**同一角色 / 场景 / 道具在不同分镜可拥有不同编号**。
- **界面主题与图标**：内置两套 QSS 主题——**深色**（默认，Fusion 风格 + 蓝紫强调色）与**浅色（白底）**，在菜单「文件 → 应用设置…」的「界面主题」下拉中切换；对话框提供「应用」按钮，可**保存并即时预览效果而无需关闭窗口**；树图标用 QPainter 在程序内绘制矢量图（工程 / 资源 / 角色 / 场景 / 道具 / 分镜 / 镜头），无需外部图片资源；编辑页统一顶部对齐、文本框限高，避免出现大块空白区域。
- **角色界面不配置编号**：`<Subject N>` 是分镜内局部编号，**角色编辑界面不显示也不允许编辑该编号**；角色的内部 id（`Subject N`）由程序在新增角色时自动生成（按现有最大号 +1），删除角色后其余角色编号保持稳定。项目树与「关联 Q 版小人」下拉均按角色名称显示。
- **场景 / 道具编号自动生成、只显示名称**：场景 `id`（Scene N）与道具 `id`（Prop N）同样由程序自动生成，**编辑界面不显示也不允许编辑**；项目树只显示其名称，**无名称时按序号显示「场景N / 道具N」**。
- **资源导入 / 导出**：菜单 **资源** 支持「导入资源...」「导出全部资源...」「导出角色...」「导出场景...」「导出道具...」。导出为 `*.h3assets.json`（含对应资源的 id、名称、描述、参考图/音频路径），导入时自动识别文件内包含的资源类型并合并进当前工程；**id 冲突时自动分配新编号**，不会覆盖已有资源。
- **角色备注名**：每个角色可填**备注名**，**仅用于界面显示、不参与生成**，用于区分同名但不同的角色；项目树、Q 版关联下拉、分镜出场角色列表会显示为「角色名（备注名）」。
- **镜头单独存文件**：保存工程时，每个**镜头 (Shot)** 写成一个独立 JSON 文件，存放在**工程文件同目录下的 `<工程名>.shots/` 文件夹**（如 `example.shots/shot_001.json`）；主工程文件只记录 `sequences` 与各分镜的 `shot_files` 列表。旧版内联分镜的工程仍可直接打开。
- **最近打开历史**：菜单 **文件 → 最近打开** 记录最近使用的工程（最多 10 个），可一键打开或清除记录；记录保存在应用配置 `appconfig.json` 中。
- **分镜提示词预览**：在**分镜编辑页**点「预览当前分镜提示词」按钮，弹窗查看该分镜（按分镜内统一编号）生成的 H3 六段结构提示词，并支持复制 / 保存为 `.txt`；仍可用「生成提示词」菜单生成整个工程。

## 构建（Windows，Qt 6.11.1 + MinGW）

本机 Qt 安装在 `D:/Qt`：

```powershell
# 1) 把 Qt 工具链加入 PATH
$env:PATH = "D:/Qt/6.11.1/mingw_64/bin;D:/Qt/Tools/mingw1310_64/bin;" + $env:PATH

# 2) 生成 Makefile 并编译（推荐 shadow build）
cd e:/Workspace/H3Hint
mkdir build
cd build
qmake ../H3Hint.pro
mingw32-make

# 3) 运行
.\H3Hint.exe
```

> 若使用 MSVC 套件，请将 `mingw_64` / `mingw1310_64` 替换为 `msvc2022_64` 并用 `nmake` / `jom`。

## 使用

1. 菜单 **文件 → 载入示例工程** 可一键填充一个完整示例（神庭快递招新），随后点 **生成提示词** 查看产出。
2. 也可 **新建工程**，在左侧树中逐项添加角色 / 场景 / 道具 / 分镜，填写资源路径与台词。
3. **保存** 会写出 `.h3json` 工程文件（资源以相对路径记录）。

## 工程 JSON 结构（摘要）

```jsonc
// 主工程文件：example.h3json
{
  "project_name": "示例",
  "settings": { "style_constraint":"" },  // 仅画风约束（工程级）；嘴型约束/出场角色在各分镜；画风/声音/音乐在应用配置中
  "subjects": [ { "id":"Subject 1", "name":"", "alias":"", "desc":"", "is_q_version":false,
                  "q_version_id":"", "view_set":"",
                  "audios":[{ "id":"Audio 1", "path":"", "desc":"" }] } ],
  "scenes":  [ { "id":"Scene 1", "label":"", "path":"", "desc":"" } ],
  "props":   [ { "id":"Prop 1", "label":"", "path":"", "desc":"" } ],
  // 分镜（视频级容器）不再内联镜头，每个分镜记录其镜头文件名（工程同目录 <工程名>.shots/ 下）
  "sequences": [ {
    "id":"Seq 1", "name":"", "lip_constraint":"", "cast":["Subject 1","Subject 2"],
    "scenes":["Scene 1"], "props":["Prop 1"],
    "shot_files": [ "shot_001.json", "shot_002.json" ]
  } ],
  "shot_dir": "example.shots"
}
```

```jsonc
// 每个镜头文件：example.shots/shot_001.json
{
  "id":"Shot 1", "label":"",
  "sub_shots":[ { "caption":"", "speeches":[
     { "subject":"Subject 2", "s2":true, "note":"", "audio":"Audio 2", "lead":"担心的使用", "text":"" } ] } ]
}
```
